## 📌 Projetos em Destaque

### 💳 PayFlow
Sistema de gerenciamento de assinaturas, faturamento e pagamentos simulados, com processamento assíncrono via RabbitMQ.
- Arquitetura backend estruturada com Spring Boot e POO
- Mensageria e processamento assíncrono de eventos com RabbitMQ
- Testes unitários com Mockito
- Simulação realista de fluxo de pagamentos
- 🔗 [Acessar repositório](https://github.com/HenzoBragas/payFlow)

### 💰 API de Controle Financeiro Pessoal
API RESTful para gerenciamento de receitas e despesas, com autenticação JWT e autorização baseada em papéis.
- Autenticação segura com JWT e autorização por papéis (`ROLE_USER`, `ROLE_ADMIN`)
- Cadastro de usuários com criptografia de senha (BCrypt)
- CRUD completo de lançamentos financeiros e categorias
- Arquitetura em camadas (Controller → Service → Repository → Security)
- 🔗 [Acessar repositório](https://github.com/HenzoBragas/FinanceControlAPI)
